# dsh-daily-schedule · 每日日程

给 DeepSeek Harness 里的陪伴角色一份「自己的日子」：每晚按人设和日程类型生成她第二天的全天日程——
几点起床、去哪、做什么、穿什么、和谁在一起，把「此刻」带进每一次对话；计划有变时，她可以自己改。

她不是在念时间表：注入里带着一段「说话方式」，让模型把这些当成她自己想做、自己去做的事来说，
不说「按照日程…」。和 [生图工作室（dsh-image-studio）](https://github.com/aa1355721445-lgtm/dsh-image-studio) 一起用时，每段日程都有对应的衣柜穿搭和场景，
她发的自拍和她此刻在哪、穿什么对得上。

## 它做了什么

| 部分 | 说明 |
| --- | --- |
| 每晚生成 | 到了设定时间（默认 22:00）用 DSH 自己的模型生成明天的日程；今天没有日程（刚装 / 电脑昨晚关着）会马上补上 |
| 日程类型 | 上班日、休息日、外出日、宅家日、加班日、摸鱼日，可开关、改权重、改「适用工作日 / 周末」、改框架，也能加自己的类型 |
| 注入 | 系统提示里写：日期星期、时间（默认每半小时一档）、今天是什么日子、此刻在做什么、接下来几段、早些时候做了什么；傍晚以后附上明天的安排；最后是一段「说话方式」 |
| `schedule_view` | 角色查看今天 / 明天 / 昨天的完整日程 |
| `schedule_adjust` | 角色临时改计划（被约出去、突然想散步、加班），改动会记下来 |
| `/life` 指令 | 按会话打开 / 关掉注入：干正事的会话 `/life off`，陪聊的会话 `/life on` |
| 穿搭与场景（v0.2） | 联动生图工作室的素材库：每段日程都配好穿着（优先用衣柜里的服饰）、标上场景库里的地方、手边的物品、和谁在一起 |
| 设置 → 每日日程 | 今天 / 明天时间线（此刻高亮，带穿着缩略图）、这一天的换装条、按要求重新生成、按衣柜补 / 重新搭配、手动编辑、日程类型、设置、往期 |

## 生成时给模型看什么

- **人设**：默认读 `<DSH_HOME>\AGENT.md`（设置 → 人格），也可以自己写；
- **这一天的类型和框架**：按明天是工作日还是周末，从启用的类型里按权重随机挑一种；
- **最近三天的日程摘要**：避免天天一个样；
- **固定设定**：她住哪、在哪上班、怎么通勤、常去的店……；
- **这一天的特别要求**：在设置页重新生成时填，例如「下午和你去看电影」；
- 装了生图工作室时，附上它的情境关键词，每段日程会带上 `situation`，发自拍时地点、穿着、情境按此刻的安排来；
- 打开「联动生图工作室」时，还会附上她的衣柜、穿搭习惯、常去的地方、物品和认识的人（见下一节）。

## 穿搭和场景（v0.2）

读[生图工作室（dsh-image-studio）](https://github.com/aa1355721445-lgtm/dsh-image-studio)的素材库（`<DSH_HOME>\image-studio\`，跟随它设置里改过的库目录），可以在 设置 → 联动生图工作室 里分开开关：

| 联动 | 生成时 | 写进日程 |
| --- | --- | --- |
| 穿搭 | 列出衣柜里的服饰和她的穿搭习惯（人物的情境穿搭、情境 / 场景 / 人物的默认服饰） | 每段的 `outfit`（衣柜里的名字）+ `outfitNote`（「外面加了件开衫」「睡衣」这类细节或库里没有的衣服） |
| 场景 | 列出场景库，要求多安排在这些地方 | 每段的 `scene` |
| 物品 | 列出道具库 | `props`：手边有什么 |
| 认识的人 | 人物库里除她（和她的 Q 版之类变体）以外的人 | `with`：和谁在一起 |

- 模型写的名字会对上库里的正名（别名也认）；库里没有的衣服转成备注，不会凭空造名字；
- 模型漏写的按规则补：活动和上一段同一种场合就延续上一段的穿着，换了场合（比如出门）按「她的情境穿搭 > 情境默认 > 场景默认 > 她的默认服饰」换一身；
- 以前生成的、没配穿搭的日程：DSH 启动后会自动给今天和明天补一次；也可以在日程页点「按衣柜补上穿搭」，或「重新搭配」整天重配；
- 注入里多了「此刻穿着…」「今天的穿着：睡衣 → 09:00 起「居家针织服」 → …」，并告诉模型生图时 characters / outfits / scene / situation 怎么填；
- 生图工作室 v0.4 起，生图没指定服饰时会直接沿用日程里她此刻的穿着，两个插件出的图衣服对得上；
- 她临时换衣服、换地方时用 `schedule_adjust` 改（可以带 `outfit` / `outfit_note` / `scene`），不写穿着就沿用那个时段原来的。

模型输出不合格时自动修补（排序、去重叠、补空档、保证从 00:00 排到 24:00）；
今天的日程生成失败会用类型模板兜底，保证一定有；明天的失败了 20 分钟后重试。

## 说话方式（v0.3）

日程是给她「自己的日子」，不是让模型念的时间表。注入的最后默认带一段说话方式，要求模型：

- 把这些当成她自己想做、自己去做的事，用「刚煮完泡面，烫死我了」「等会儿想去便利店买布丁」这种口吻说；
- 不说「按照日程」「按计划」「日程上写着」「我的安排是」「根据时间表」，也不提「日程」「计划表」「时间段」这些词；
- 不报时间段、不列清单，对方问起时像朋友闲聊一样挑一两件说；
- 临时改主意时直接说决定（「算了不出门了」），不说「我调整一下计划」；
- 不用每句都提自己在干嘛，状态（刚睡醒、吃饱了、深夜犯困）体现在语气里。

注入本身的措辞也改成了她的视角（「她正在…」「她待会儿想做…」），`schedule_view` / `schedule_adjust` 的说明和返回结果里也都提醒别把「日程」说出口。
在 设置 → 注入到对话 里可以关掉，或改成自己的写法（`{角色名}`、`{称呼}` 会换成设置里的名字）；留着默认的话，插件更新时会跟着改进。

## 分会话注入：干正事的时候不打扰（v0.4）

日常是通过系统提示注入的，默认每个会话都会带上。为了不让它影响正经任务：

- **子代理会话始终不注入**：派出去写代码、查资料的子代理拿不到她的日常；
- **注入里固定带一句「正事优先」**：日常只是背景，让她做事就认真做完，不能因为她「在睡觉」「出门了」就敷衍；
- **按会话开关**：在任意会话里发指令——

  | 指令 | 作用 |
  | --- | --- |
  | `/life off` | 这个会话不再注入她的日常（适合干活） |
  | `/life on` | 这个会话打开注入 |
  | `/life auto` | 恢复默认 |
  | `/life` | 查看这个会话现在注不注 |

- **两种默认**（设置 → 注入到对话 →「注入到哪些会话」）：
  - **所有会话**：默认都带上，个别干活的会话 `/life off`；适合主要拿 DSH 陪聊；
  - **只在打开的会话**：默认都不带，想和她聊天的会话 `/life on`；适合主要拿 DSH 干活。

单独设置过的会话记在 `<DSH_HOME>\daily-schedule\sessions.json`，设置页里能看到列表、一键恢复默认。
关掉之前已经注入过的内容还留在那个会话的记录里，想完全干净就新开一个会话再 `/life off`（或者用「只在打开的会话」模式）。

## 和提示词缓存

注入内容只在时段切换、或时间跨过半小时（可设为只看时段）时才会变；DSH 只在系统提示有变化时才追加，
不会每轮都让模型重读一遍。精确到分钟的时钟由 DSH 自带的 time-context 每 10 分钟提供一次。

## 安装

需要：DeepSeek Harness 桌面版。生成日程用的是 DSH 里已经配好的模型，不用另填 Key。
想要穿搭、场景和自拍联动，再装上 [dsh-image-studio](https://github.com/aa1355721445-lgtm/dsh-image-studio)（可选）。

**方式一：在 DSH 里装（推荐）**

1. 打开 DSH 侧栏的 **插件 → 添加插件**（或点箭头选「安装第三方插件」）。
2. 把本仓库地址粘进输入框，点 **安装**：

   ```
   https://github.com/aa1355721445-lgtm/dsh-daily-schedule
   ```

3. 装好后点 **立即启用**。设置里没出现「每日日程」的话，完全退出 DSH 再打开一次。
4. 到 **设置 → 每日日程 → 设置** 填角色名、她怎么称呼你、时区；「日程类型」里关掉不想要的类型（比如不想让她上班，就关掉上班日和加班日）。今天的日程会在一分钟内自动生成。

**方式二：命令行**

先完全退出 DSH（托盘里也退出），然后在 PowerShell 里：

```powershell
dsh plugin --profile desktop add https://github.com/aa1355721445-lgtm/dsh-daily-schedule
```

`dsh` 不在 PATH 上时，用 DSH 安装目录里的完整路径：`& "<DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add https://github.com/aa1355721445-lgtm/dsh-daily-schedule`。

**升级**：DSH 里第三方插件通过「卸载 → 重新安装」升级；日程和设置都存在 `<DSH_HOME>\daily-schedule\`，卸载不会删掉。

**本地开发**：`git clone` 下来后用 `dsh plugin --profile desktop add link:<克隆目录>` 安装，改代码直接生效（宿主端改动需重启 DSH，只改 `lib/client.js` 刷新页面即可）。

## 数据

```
<DSH_HOME>\daily-schedule\
  config.json          设置与日程类型
  sessions.json        单独用 /life 开关过的会话
  days\YYYY-MM-DD.json 每天的日程（含临时调整记录）
```

node tests/smoke-host.mjs      # 生成 / 定时 / 兜底 / 注入 / 工具 / HTTP（模拟 DSH 模型与时间）
